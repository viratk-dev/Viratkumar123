W—01 / Plinth — Case study

Plinth

Build apps on your phone.

Android · v1.8.0 · 2.6 MB · No sign-in · Live

Visit Plinth ↗ Download APK ↗

Product design, Android development, AI build pipeline, launch site

React + Tailwind web apps, published to a live link

Live, v1.8.0 (2026)

The brief

Most app builders assume a laptop, an account and a subscription. Plinth puts the whole loop on an Android phone: describe an idea in one sentence, watch Plinth AI write the code, try it live, and put it on the web. No computer, no sign-in.

2.6 MB
Android download
1 tap
To a live public link
0
Sign-ins required
₹0
Free, no ads

What it does

  1. 01

    One sentence to a live link

    Describe the app in plain words, with an image if it helps. Plinth AI writes real React + Tailwind files one by one, runs the preview on the phone, and publishes it in one tap.

    1. Describe
    2. Build
    3. Preview
    4. Publish
  2. 02

    Change it by chat

    Ask for a change and Plinth makes it. Every change is a saved version, so undo is one tap, with phone and desktop previews and a console when needed.

  3. 03

    Builds in the background

    Minimise Plinth or swipe it away. The build keeps going and a notification says when the app is ready; if Android stops it, the build resumes next launch.

  4. 04

    Keys stay on the phone

    Plinth AI is built in and free. When an app needs an API key, Plinth asks in chat and stores it encrypted on the device. Bring your own key if you prefer.

Private by default

Free. No sign-in. No ads. No analytics. There is no account to make and nothing tracking you: open it and start building.

Stack

Describe, code, preview and publish, the whole build loop in a 2.6 MB Android app.

Android / AI code generation / React + Tailwind / Cloudflare Workers (publishing) / Vercel (launch site)

The brief

Free music on Android usually means ads between songs, an account, and offline listening locked behind a subscription. MusiCap removes all three: search any song, play it start to finish, keep it for offline and sing along, with nothing to sign up for.

What it does

  1. 01

    The real song comes first

    Search a song and the original by its artist sits on top. Covers, remixes and slowed versions stay out of the way, with songs, albums, artists and playlists in one search.

  2. 02

    Play one song, get a radio

    Start a radio from any song, artist or album. Home fills with quick picks drawn from your own listening, with no account needed.

  3. 03

    A player that lets music lead

    Edge-to-edge artwork, colours from the album, synced lyrics, queue and sleep timer, lock-screen controls, and background play with the screen off.

  4. 04

    Library that works offline

    Liked songs, playlists and downloads that play with no network. Light by default, with dark mode a tap away.

Private by default

Likes, playlists, downloads and history live on your phone. No account, no email, no phone number, and every release is signed.

SPARK

Never lose a great idea.

The brief

Ideas arrive at inconvenient moments — on a walk, mid-conversation, half-asleep. Most note apps ask for an account, a sync plan and a lot of storage before you can keep one. SPARK is the opposite: open it, speak or type, and the thought is safe on your phone. Later, it quietly brings the forgotten ones back.

≈5.2 MB
Android download
100%
Local-first storage
0
Accounts required
3
Export formats

What it does

  1. 01

    Voice sparks

    Record a voice note, pick the recording quality, and optionally turn speech into searchable text on the device. Audio-only mode skips transcription entirely.

  2. 02

    Resurfacing

    Old and favourite sparks return when they deserve another look (“Still relevant?”), so you can keep them close or archive them quietly.

  3. 03

    Four clear stages

    Every idea moves through Active → Developing → Built → Archived.

    1. Active
    2. Developing
    3. Built
    4. Archived
  4. 04

    Portable vault

    Export as JSON or Markdown, or make a full ZIP backup with audio. A storage indicator shows what lives on the device.

Private by default

Ideas live in a SQLite database on your phone, and voice recordings stay there too. No account, no cloud, nothing to sign up for.
